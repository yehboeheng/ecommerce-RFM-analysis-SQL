# 電商 RFM 客戶分群與營收貢獻分析

## 📌 專案簡介
本專案運用 **SQL** 與 **Python** 進行電商交易資料處理，並透過 **RFM（Recency, Frequency, Monetary）模型** 對客戶進行價值分層與行為分析。透過數據視覺化，協助企業辨識高價值客群、評估客戶流失風險，並提供具體的精準行銷與資源配置建議。

## 🛠️ 使用工具與技術
* **數據查詢與處理**：SQL（資料清洗、資料聚合、Window Functions 視窗函數）
* **數據分析與視覺化**：Tableau Public / Python
* **分析模型與理論**：RFM 價值模型、帕雷托法則（80/20 法則）

## 📊 核心洞察與專案成果
1. **核心營收貢獻**：成功辨識出「最佳客戶」客群，雖然人數佔比非最高，但貢獻了 **69.28%** 的總營收，為企業核心資產。
2. **流失預警與召回**：識別出「快流失/已流失」客群（共 1,523 人），提供行銷團隊作為重點召回與優惠發放的依據。
3. **動態趨勢追蹤**：整合時間軸數據，監控不同客群在各月份的消費波動與回購率變化。
